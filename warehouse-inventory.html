📊 Data Structure Comparison: Linked List vs Array

Doubly Linked List (Current Implementation)

Insert at Beginning O(1)
Insert at End O(1)
Delete Specific Node O(1)*
Search by Value O(n)
Access by Index O(n)

* O(1) when you have direct reference to the node

Array Implementation

Insert at Beginning O(n)
Insert at End O(1)
Delete Specific Node O(n)
Search by Value O(n)
Access by Index O(1)

Arrays require shifting elements on insert/delete
